# Everrise — 공부 RPG (설치형 웹앱)

공부해야 골드·뽑기권·이벤트가 쌓이고, 쌓은 것으로 모험·전투·상점·뽑기를 즐기는 RPG예요.
견습 마법사로 시작해 하루 3번, 40분 공부를 1년 가까이 이어 가면 현자가 되는 구조예요.

## 1. 파일 5개 (모두 GitHub 저장소 맨 위에 올리기, 폴더 X)

| 파일 | 하는 일 | 꼭 필요? |
|---|---|---|
| `index.html` | 앱 본체(화면, 규칙, AI 호출 모두 이 안에 있어요) | 필수 |
| `manifest.json` | 설치할 때 쓰는 앱 이름·아이콘 정보(이름: Everrise) | 설치하려면 필수 |
| `sw.js` | 앱을 기기에 저장해 두는 파일(서비스 워커) | 설치하려면 필수 |
| `icon-192.png` | 홈 화면 아이콘(작은 것) | 설치하려면 필수 |
| `icon-512.png` | 홈 화면 아이콘(큰 것) | 설치하려면 필수 |

- 파일 이름은 정확히 위와 같아야 해요. `index (2).html`처럼 번호가 붙으면 안 열려요.
- 나중에 앱을 고칠 때는 보통 `index.html`과 `sw.js`만 덮어써서 올리면 돼요.

## 2. 올리는 방법 (GitHub Pages)
1. 저장소에서 "Add file" → "Upload files"로 파일 5개를 올리고 "Commit changes".
2. Settings → Pages → Source: "Deploy from a branch", Branch: `main`, 폴더: `/ (root)` → Save.
3. 1~2분 뒤 Pages 화면에 뜬 주소(`https://아이디.github.io/저장소이름/`)를 열어요.
4. 크롬 ⋮ 메뉴의 "앱 설치"(또는 "홈 화면에 추가")를 눌러요.
5. 파일을 고쳐 올린 뒤 예전 화면이 보이면 새로고침(PC는 Ctrl+Shift+R)해요.

## 3. AI 키 (Gemini)
- aistudio.google.com에서 Gemini API 키를 만들어요(무료 등급이 있어요).
- 앱에서 처음 AI가 필요할 때(첫 실행의 과목 스탯 정하기, 공부 판정 등) 키 입력창이 뜨면 붙여 넣어요.
- 키는 그 기기의 브라우저에만 저장돼요. 파일에 들어 있지 않아요. 남에게 보내거나 스크린샷에 찍지 마세요.
- 모델 이름이 바뀌어 오류가 나면 `index.html`에서 `gemini-3.8-flash`를 찾아 오류 문구가 알려 주는 이름으로 바꿔요.
- 공부 검사에는 더 빠른 `gemini-3.5-flash-lite`를 써요. 이 모델이 없어지면 자동으로 `gemini-3.8-flash`로 바꿔서 검사해요.
- 무료 등급은 보낸 내용(공부 중 사진 포함)이 Google 제품 개선에 쓰일 수 있어요.

## 4. 핵심 규칙
- **공부**: 40분 타이머 + 카메라 타임랩스. AI가 공부 중인지 구간마다(6구간, 구간당 사진 2장) 미리 검사하고, 60% 이상이면 인정해요.
  - 인정 보상: 골드 10,000 · 뽑기권 1장 · 이벤트 3개 · 선택한 과목의 스탯 +1 · 명성 +10 · HP/MP 회복.
  - 하루 3번 모두 하면 보너스 골드 10,000 + 뽑기권 1장.
  - 테스트 모드(40초)는 판정만 해 보고 보상은 주지 않아요.
- **공부 목숨**: 최대 4개(스토리 HP와 별개). 하루 3번을 못 채우면 부족한 횟수만큼 자정에 차감, 하루를 모두 채우면 다음 날 +1. 목숨이 0이 되면 골드·아이템·무기·유물을 모두 잃고 목숨 4개로 돌아와요.
- **휴식/멈춤**: 공부 중 "5분 휴식"(공부당 1번) 또는 상점의 "멈추기권"(10분). 멈춘 만큼 공부 시간이 뒤로 늘어나요.
- **등급**: 견습 마법사(7등급) → 수습 → 정식 → 숙련 → 상급 → 대마법사 → 현자(1등급). 누적 공부 0·30·150·350·600·850·1,080회에 승급 시험 자격이 생기고, 시험(보스 이벤트)을 통과해야 승급해요.
- **스탯**: 힘·지능·민첩·행운·건강·마나. 처음에 고른 과목(최대 6개)에 AI가 스탯을 하나씩 연결해요. 연결 안 된 스탯은 그냥 이름으로 표시돼요. 건강은 최대 HP, 마나는 최대 MP를 올려요.
- **모험**: 이벤트 1개를 쓰면 AI가 이야기를 만들어요. 약 30%는 턴제 전투(공격/스킬/방어/포션/도망, 15%는 보스), 10%는 아이템 사용 이벤트, 3%는 아이템 발견 이벤트예요. 터무니없는 행동은 거부되고, 마법 두루마리를 쓰면 1회 허용돼요.
- **스킬 7개·유물 8종**: 스킬은 등급이 오르면 풀리고 MP를 써요. 유물은 가지면 항상 효과가 적용돼요.
- **뽑기**: 등급 일반 62% · 희귀 27% · 영웅 9% · 전설 2%. 카테고리는 골드/소모품/스탯업/무기/기타/유물. 특별(공부 목숨 회복약) 1%, 50번째 뽑기는 전설 확정. 무기·소모품·기타 물건은 AI가 만들어요.
- **상점**: 오전 0시와 오후 12시마다 진열이 바뀌고 재고가 채워져요. 가격: 포션 8,000 · 두루마리 32,000 · 스탯 장비 20,000 · 멈추기권 60,000골드.
- **연속 출석 보상**: 7일·30일·100일·200일·365일. 달력은 기록 탭에 있어요.
- **특례 승인**: 불가피한 사정을 적고 증빙 사진을 찍으면 그날 목숨이 차감되지 않아요(한 달 3번, 하루 1번, 자동 승인).
- **복습 퀴즈**: 공부 과목을 고르면 인정 뒤 퀴즈 3문제가 나와요(맞힌 개수당 3,000골드, 전부 맞히면 뽑기권).
- **알림**: 평소 공부하던 시간에 공부를 안 하면 알려요(앱이 열려 있을 때만).
- **월간 타임랩스**: 기록 탭에서 달별 영상을 합쳐 내려받고, 내려받은 뒤 게임에서 지울 수 있어요.
- **저장/복원**: 기록 탭 맨 아래에서 저장 코드를 만들어 보관하고, 데이터가 사라졌을 때 붙여 넣어 복원해요(영상은 포함 안 돼요).

## 5. 알아둘 점
- 진행 상황은 이 기기의 브라우저에 저장돼요. 브라우저 데이터를 지우면 사라지니 저장 코드를 가끔 만들어 두세요.
- 공부 중에는 앱 화면을 켜 두세요. 다른 앱으로 나가면 촬영과 AI 검사가 멈춰요. (다른 앱 이탈 감시는 아직 없어요.)
- PIN은 화면 잠금용이에요. 진짜 로그인이 아니고 기기 안에만 저장돼요.
- 닉네임·학년·목표·과목 스탯은 AI가 이야기를 만들 때 함께 전달돼요.
- 카메라는 `https` 주소에서만 되고, 권한 허용이 필요해요. 막히면 크롬 주소창 왼쪽 아이콘 → 권한에서 카메라를 허용하세요.
- 월간 영상 만들기는 폰 브라우저에 따라 안 될 수 있어요.

## 6. 문제 해결
| 증상 | 확인할 것 |
|---|---|
| 주소가 404 | Pages가 켜졌는지, 파일 이름이 `index.html`인지, 1~2분 기다렸는지 |
| README 제목만 보임 | `index.html` 이름에 공백/번호가 없는지 |
| 카메라가 안 켜짐 | 주소가 `https`인지, 크롬과 폰 설정의 카메라 권한 |
| AI 오류(모델 관련 문구) | 3번의 모델 이름 바꾸기 |
| AI 오류(429) | 무료 한도 초과, 잠시 뒤 다시 시도 |
| 앱 설치 메뉴가 안 보임 | 5개 파일이 모두 올라갔는지, `https` 주소인지 |
